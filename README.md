# מתמלל עברית (ivrit.ai)

מתמלל קבצי שמע (m4a, mp3, wav ועוד) לקובץ טקסט, עם ממשק גרפי פשוט. התמלול רץ מקומית על המחשב.
אפשר גם להפריד בין הדוברים (מקומית), ולקבל כותרת, סיכום ומשימות להמשך לכל שיחה (בעזרת Claude) – ראו "אפשרויות נוספות".

## התקנה (חד-פעמית)

**הדרך הקלה:** מורידים את `Setup-IvritTranscriber-vX.Y.Z.cmd` מעמוד ה-**Releases** ולוחצים עליו לחיצה כפולה. הוא עושה את כל השלבים שלמטה.

**אם ההתקנה לא מתחילה מיד**, נסגרת מיד או נעצרת עם שגיאת הרשאה: לוחצים על הקובץ **קליק ימני ← הפעל כמנהל** (Run as administrator) ומאשרים. אם Windows מבקש שם וסיסמה של משתמש אחר, ההתקנה תיכנס לתיקייה של המשתמש ההוא, ולכן עדיף להתקין מהמשתמש שישתמש בתוכנה.

התקנה מקבצי המקור:

1. **Python 3.10 ומעלה** – אם אינו מותקן, ההתקנה תציע להתקין אותו אוטומטית (winget).
   בהתקנה ידנית מ-python.org יש לסמן: **Add python.exe to PATH**.
2. לחיצה כפולה על **`install.cmd`**.

ההתקנה:
- יוצרת תיקייה ייעודית: `%USERPROFILE%\IvritTranscriber`
  (לתיקייה אחרת: `install.cmd D:\Transcriber`)
- מעתיקה אליה את `transcribe_ivrit.py` ואת הממשק, ויוצרת בה את תיקיית התוצרים `Transcripts`
- יוצרת סביבת פייתון פרטית (`.venv`) ומתקינה בה:
  `pip install faster-whisper`, `pip install -U av`, `pip install -U anthropic` ו-`pip install -U sherpa-onnx`
- יוצרת קיצור דרך **Ivrit Transcriber** בשולחן העבודה ובתפריט התחל

## שימוש – ממשק גרפי

1. לחיצה כפולה על **Ivrit Transcriber** בשולחן העבודה.
2. גוררים קובץ שמע לחלון (או לוחצים לבחירה).
3. לוחצים **תמלל**.
   בזמן התמלול אפשר **להשהות** (ההשהיה נכנסת לתוקף בסוף המשפט הנוכחי, והזמן המושהה לא נספר) או **לבטל** (לחיצה שנייה מאשרת). אחרי ביטול הקובץ נשאר טעון ואפשר לתמלל אותו שוב.
4. כל תמלול נשמר בתת-תיקייה משלו, לפי תאריך ושעת תחילת התמלול:
   ```
   IvritTranscriber\Transcripts\2026-10-13_22-45-10\
       הקלטה.m4a   הקלטה.txt   הקלטה.srt
   ```
   הכפתור **תיקיית התמלולים** (בראש החלון) פותח את התיקייה הראשית, והכפתור **הצגה בתיקייה** (בסיום) פותח את תיקיית התמלול הנוכחי.

> בפעם הראשונה המודל (~1.6GB) יורד מהאינטרנט. בפעמים הבאות הוא נטען מהמטמון המקומי.

## מה רץ מקומית ומה דרך האינטרנט

| | איפה זה רץ | אינטרנט |
|---|---|---|
| **תמלול** | מקומית על המחשב | רק בפעם הראשונה (הורדת המודל, כ-1.6GB) |
| **הפרדת דוברים** | מקומית על המחשב | רק בפעם הראשונה (מודל קטן, כ-33MB) |
| **כותרת, סיכום, משימות, זיהוי שמות** | Claude של Anthropic | תמיד – רק טקסט התמלול נשלח, לא ההקלטה |

בחלון המתמלל ליד כל אפשרות יש אייקון: מסך = מקומי, ענן = דרך האינטרנט.

## אפשרויות נוספות: הפרדת דוברים, כותרת, סיכום ומשימות

מתחת לכפתור **תמלל** יש **אפשרויות נוספות**, ואפשר לסמן כמה מהן:

- **הפרדת דוברים** – כל שורה בתמלול מסומנת במי שאמר אותה:
  ```
  [00:01:12] דובר 1: מתי נוח לך להיפגש?
  [00:01:15] דובר 2: ביום שלישי בבוקר.
  ```
  רץ **מקומית** על המחשב (sherpa-onnx עם מודלי pyannote ו-wespeaker). בפעם הראשונה יורדים שני מודלים קטנים (כ-33MB) לתיקייה `models`, ואחר כך זה עובד גם בלי אינטרנט. מוסיף כחצי דקה לכל 10 דקות הקלטה.
  **כדאי לבחור את מספר הדוברים** (ברירת המחדל: 2) – זה מדויק יותר מ"לא ידוע". שני קולות דומים (למשל שני גברים בטלפון) עלולים להתפצל במצב האוטומטי.
  תגובות קצרות מאוד ("כן", "אהה") מסומנות לפעמים לדובר הלא נכון. אם בוחרים גם סיכום, Claude מקבל את הסימונים ומשתמש בשמות כשהם עולים בשיחה ("היי דנה").
  אפשר לבחור הפרדת דוברים רק לפני התמלול.
  **שילוב עם Claude:** אם בוחרים גם כותרת, סיכום או משימות, Claude בודק לפי התוכן (פניות בשם, שאלה ותשובה, ברכות) מי אמר את השורות שהקול לא היה בטוח בהן. שורות שהקול בטוח בהן נשארות כמו שהן. בשיחה קצרה עם שני קולות דומים, שבה הקול לא מצליח להפריד בכלל, Claude מחלק את כל השורות לפי התוכן. במסך הסיום מופיע כמה שורות תוקנו כך.
  **שמות הדוברים:** במסך הסיום אפשר לתת לכל דובר שם (ליד כל שדה מופיע משפט שהוא אמר, כדי לזהות אותו). השם מתעדכן בתמלול, ב-srt ובסיכום. אם בוחרים גם כותרת, סיכום או משימות, Claude ממלא שמות בעצמו כשהם ברורים מהשיחה ("היי דנה").

**ביטחון וודאות** (במסך הסיום, עם הסבר במעבר עכבר):
- **ביטחון בתמלול** – כמה מודל התמלול בטוח בעצמו, בממוצע. זו הערכה של המודל, לא בדיקה מול טקסט נכון.
- **ודאות בזיהוי הדוברים** – באיזה חלק מהמשפטים הקול דומה בבירור לדובר שסומן. בבדיקה על שיחה מסומנת ידנית, משפטים "ודאיים" היו נכונים כמעט תמיד (87 מ-88), והטעויות היו בעיקר במשפטים הלא ודאיים ובתגובות קצרות ("כן", "אהה").
- אי אפשר להציג "אחוז דיוק" אמיתי: בשביל זה צריך לדעת מראש מה נאמר ומי אמר.
- **כותרת** – שם קצר שמתאר את השיחה. הוא מתווסף גם לשם התיקייה: `2026-10-14_11-30-00 - תיאום פגישה עם הקבלן`.
- **סיכום** – על מה דיברו, הנקודות העיקריות וההחלטות.
- **משימות להמשך** – מה צריך לעשות, מי אחראי ועד מתי (כשזה נאמר בשיחה).

התוצרים מופיעים בלשונית **סיכום ומשימות** בסיום, ונשמרים גם בקובץ `<שם>_סיכום.txt` בתיקיית התמלול.
אפשר להוסיף אותם גם אחרי שהתמלול הסתיים, או ליצור אותם מחדש: פותחים את **אפשרויות נוספות** במסך הסיום, מסמנים מה ליצור ולוחצים על הכפתור (למשל **יצירת הסיכום והמשימות**).
אם יצירת הסיכום נכשלה (למשל אין אינטרנט), התמלול עצמו כבר שמור, ויש כפתור **ניסיון נוסף**.

**איך זה עובד ומה נשלח:** את הכותרת, הסיכום והמשימות יוצר Claude (המודל `claude-opus-5-5` של Anthropic) דרך האינטרנט.
רק **טקסט התמלול** נשלח, ורק כשמסמנים אחת מהאפשרויות. ההקלטה עצמה לא יוצאת מהמחשב, והתמלול עצמו תמיד רץ מקומית.

**מפתח API (פעם אחת):**
1. נכנסים ל-[console.anthropic.com](https://console.anthropic.com/settings/keys), נרשמים, מטעינים יתרה ויוצרים מפתח (מתחיל ב-`sk-ant-`).
2. במתמלל: **אפשרויות נוספות** ← מדביקים את המפתח ← **שמירת המפתח**. המפתח נבדק מול Claude ונשמר מוצפן (Windows DPAPI – רק המשתמש הזה במחשב הזה יכול לפענח אותו) בקובץ `settings.json` בתיקיית ההתקנה.

**עלות:** משלמים ל-Anthropic לפי השימוש, בטוקנים. טוקן הוא חלק קטן של מילה. בעברית יוצאים בערך 700 טוקנים לכל דקת שיחה.
המחיר של `claude-opus-5-5` (אוקטובר 2026): **4$ למיליון טוקנים שנשלחים** (טקסט התמלול וההוראות) ו-**20$ למיליון טוקנים שמתקבלים** (הכותרת, הסיכום, המשימות וגם החשיבה של המודל).

הערכה לתמלול אחד, כשמסמנים כותרת, סיכום ומשימות יחד:

| אורך השיחה | בלי הפרדת דוברים | עם הפרדת דוברים |
|---|---|---|
| 5 דקות | 5 סנט עד 11 סנט | 7 סנט עד 13 סנט |
| 10 דקות | 7 סנט עד 13 סנט | 11 סנט עד 17 סנט |
| 30 דקות | 13 סנט עד 21 סנט | 24 סנט עד 34 סנט |
| שעה | 23 סנט עד 32 סנט | 44 סנט עד 59 סנט |

- **עם הפרדת דוברים** התמלול נשלח פעמיים: פעם כטקסט רגיל ופעם בשורות ממוספרות, כדי ש-Claude יוכל לבדוק מי אמר כל שורה. לכן זה יקר יותר.
- **כותרת בלבד** זולה יותר, כי התשובה קצרה מאוד.
- **בחלון עצמו** מופיעה הערכה לשיחה שטענתם, לפי האורך שלה והאפשרויות שסימנתם.
- **ליצור מחדש** עולה כמו פעם ראשונה.
- אלה הערכות. העלות המדויקת של כל בקשה מופיעה ב-[console.anthropic.com](https://console.anthropic.com/usage), ושם אפשר גם להגדיר תקרת הוצאה חודשית.

## שימוש – PowerShell

```powershell
cd $env:USERPROFILE\IvritTranscriber
.\transcribe.cmd .\my_audio.m4a            # מדויק
.\transcribe.cmd .\my_audio.m4a --beam 1   # מהיר
```

## התקנה על מחשב אחר

**קובץ אחד:** שולחים את `Setup-IvritTranscriber-vX.Y.Z.cmd` (כ-35KB) – מורידים אותו מעמוד ה-Releases במאגר, או בונים מקומית עם `build_setup.ps1` (נוצר בתיקייה `dist`).
במחשב השני: לחיצה כפולה עליו – הוא פורס את הקבצים לתיקייה זמנית, מריץ את ההתקנה ומנקה אחריו.
(לתיקייה אחרת: `Setup-IvritTranscriber-vX.Y.Z.cmd D:\Transcriber`)

- אם Windows מציג "Windows protected your PC": **More info ← Run anyway**.
- אם ההתקנה לא מתחילה מיד או נסגרת מיד: **קליק ימני על הקובץ ← הפעל כמנהל** (Run as administrator).

- אחרי שינוי בקוד, בונים מחדש את הקובץ: `powershell -ExecutionPolicy Bypass -File build_setup.ps1`
